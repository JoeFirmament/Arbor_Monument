# 树下旧闻——苏州古树地方史料指南

本指南为“以树为碑”项目整理苏州古树的地方历史资料入口，供研究、采集、编辑与版权复核使用。重点覆盖地方志、园林志、文人文集、近现代影像、苏州地方志数据库及新编方志。

- 版本日期：2026-08-16
- 适用范围：当前私人研究版本
- 相关文档：[《资料源流——“以树为碑”外部资源与使用指南》](./资料源流——外部资源与使用指南.md)

## 1. 资料体系与使用顺序

项目中的历史内容分为三条资料线：

| 资料线 | 主要问题 | 优先来源 |
|---|---|---|
| 地方史实 | 地点沿革、建筑、园林、机构、修葺及历史事件 | 苏州地方志数据库、府县志、园林志、新编方志 |
| 文人文本 | 人物是否到过此地、写过什么、是否明确提及树木 | 别集、诗文集、题咏、日记、游记及旧志艺文门 |
| 历史影像 | 某一时期的环境、建筑、道路、水系和植被面貌 | 大学影像库、档案机构、图书馆及有明确权利说明的馆藏 |

推荐的核验顺序是：

1. 从苏州官方地方志和地情资料确认基本事实；
2. 回到旧志、文集或原始影像核对细节；
3. 用大学图书馆或国家图书馆目录确认作者、版本和馆藏；
4. 最后判断材料是仅供研究、可以引用，还是允许在网页中展示。

### 2.2 地方志中的检索门类

古树资料不一定出现在“古树”或“林业”条目中。检索时应同时查看：

`山川`、`园林`、`古迹`、`寺观`、`祠庙`、`学校`、`坊巷`、`人物`、`艺文`、`物产`、`风俗`、`灾异`

其中：

- `园林`、`古迹`：园址、建筑、叠山、水系与修葺；
- `寺观`、`祠庙`、`学校`：文庙、寺院及祠宇中的树木环境；
- `人物`、`艺文`：园主、地方官、文人游历、诗文和题记；
- `灾异`：风灾、火灾、兵燹、洪水等可能影响古树存续的事件；
- `物产`：地方树种、栽培传统和用途。

## 3. 园林志与园林专题文献

### 3.1 沧浪亭旧志

苏州市地方志工作办公室已发布[《沧浪亭旧志汇编》点校出版](https://dfzb.suzhou.gov.cn/dfzb/xszl/202606/985f2227b9074f9db04a304acd9ac507.shtml)的消息。该书汇集：

- 《沧浪小志》
- 《沧浪亭志》
- 《沧浪亭新志》
- 《苏州沧浪亭图咏》
- 《沧浪亭图题咏》

这组资料可用于整理沧浪亭的建筑、植物、修葺、题咏和人物活动时间线。

旧志原文可能已经进入公有领域，但2026年出版的点校文字、标点、注释、编排与版式属于现代整理成果。项目中应优先寻找原刻本或早期影印本；使用现代点校本时，只整理事实、记录出处并作必要的短引，不复制整页或大段文字。

### 3.2 建议检索的园林文献

| 类别 | 建议题名 |
|---|---|
| 苏州总志、府县志 | 《吴郡志》《姑苏志》、历代《苏州府志》《吴县志》《长洲县志》《元和县志》 |
| 园林与地方掌故 | 《苏州园林志》《吴门表隐》《百城烟水》 |
| 造园与陈设 | 《园冶》《长物志》 |
| 单园文献 | 各园的“旧志”“园志”“小志”“图咏”“题咏”“修缮记录” |

引用这些书目时，应记录具体版本。后出的校注本、点校本和摄影图录不能因其底本年代久远而被视为公有领域。

## 4. 古籍、旧方志与文人文集

### 4.1 国家图书馆

[中华古籍智慧化服务平台](https://guji.nlc.cn/)是国家图书馆目前提供的新版古籍入口，适合检索府志、县志、诗文集、园林著作与地方总集。部分阅读功能可能需要注册或登录；若平台入口调整，可从[国家图书馆数字资源门户](https://www.nlc.cn/web/dzzn/dzzy/)重新进入。

旧“中华古籍资源库”地址使用 `http://read.nlc.cn/`，其 HTTPS 连接目前不能正常建立，容易被现代浏览器或应用的安全策略拦截。本项目不再把旧地址作为推荐入口。

建议优先查找：

- 范成大集及《吴郡志》；
- 苏舜钦集；
- 文徵明、唐寅、沈周相关诗文集；
- 归有光、张岱、袁宏道等人的园林题记和游记；
- 苏州府志、吴县志、长洲县志、元和县志；
- 园林图咏及苏州地方诗文总集。

古籍原文和扫描图的权利状态需要分别判断。古籍原文可能已经无著作权，数据库制作的扫描图、页面和元数据却不一定采用开放许可。

### 4.2 CADAL

[CADAL大学数字图书馆](https://cadal.edu.cn/)收录大量地方志、近现代图书、文集与图录，适合补充国家图书馆未提供全文的资料。

其[版权声明](https://cadal.edu.cn/index/copyrightStatement)明确将资源用于教学、科研和个人学习等合理使用场景，同时禁止批量下载、非法传播和商业使用。CADAL因此适合作为内部查阅与原文核对工具，不宜直接作为网页图片来源。

### 4.3 哈佛大学馆藏

[Harvard HOLLIS](https://hollis.harvard.edu/)和[Harvard LibraryCloud](https://api.lib.harvard.edu/v2/items.json?q=Suzhou&limit=5)可以检索哈佛燕京图书馆收藏的苏州地方志、地方文献、图录和文集。

馆藏目录可用于：

- 核对作者、版本、出版信息和主题词；
- 发现苏州旧街巷图录、地方历史图录和口述历史资料；
- 确认中文古籍、方志丛刊及江苏艺文资料的馆藏位置。

HOLLIS首先是权威书目与馆藏目录。“检索到馆藏”不等于“可以下载全文”；部分资源只有馆藏记录，部分电子资源限哈佛校内读者访问。

### 4.4 辅助全文检索

| 资源 | 适合用途 | 注意事项 |
|---|---|---|
| [Chinese Text Project 中国哲学书电子化计划](https://ctext.org/zh) | 古籍全文检索、定位句子和篇目 | 适合发现线索；正式引用应对照可靠底本 |
| [中文维基文库](https://zh.wikisource.org/) | 查找和复制公有领域古籍文本 | 核对校勘质量、版本与页面许可 |
| [Internet Archive](https://archive.org/) | 查找海外图书馆扫描的旧志、文集和图录 | 权利状态按条目确认；上传者说明不一定充分 |

## 5. 民国及近代苏州影像

### 5.1 布里斯托大学：中国历史照片

[Historical Photographs of China](https://www.hpcbristol.net/)是大学维护的近代中国历史影像库。使用[地点为 Suzhou 的检索结果](https://www.hpcbristol.net/search?query=&location=Suzhou)，可排除上海“苏州河”造成的误命中。2026年8月核验时，该地点筛选返回36张影像，包括：

- 木渎河道及太平军旧堡；
- 玄妙观弥罗宝阁；
- 盘门、娄门及城墙水道；
- 留园；
- 苏州庭院、廊道、街巷及太湖周边景观。

影像采用 **CC BY-NC-ND 4.0**。研究、教育和非商业用途可以下载、传输或打印，但必须注明来源；不得用于商业用途，也不得裁切、上色、拼贴或制作其他衍生作品。若项目将来公开商业化，应重新审核并联系馆方或原收藏者。

建议保存的署名信息包括：图片题名、HPC编号、摄影者、收藏者或藏品系列、University of Bristol、原始链接和许可链接。

### 5.2 美国国会图书馆

[Library of Congress 图片检索](https://www.loc.gov/photos/)中有明确的苏州园林照片，例如：

- [Soochow gardens](https://www.loc.gov/item/2005683250/)
- [Soochow Gardens: Shihtselin Garden](https://www.loc.gov/item/94513891/)

这些条目通常有永久链接、书目信息和可下载图像。版权状态须按单个条目的 Rights & Access 或 Rights Advisory 判断；收藏于美国国会图书馆不等于自动进入公有领域。

### 5.3 苏州官方老照片栏目

苏州市地方志工作办公室持续发布“苏州老照片”专题，例如[《苏州火车站的120年》](https://dfzb.suzhou.gov.cn/dfzb/szdq/202607/bab8189c5c5142b2b2b7d1901ba1c22e.shtml)。这类文章适合确认地点、历史背景和原始图片出处，也可用于建立建筑、道路、园林与水系的变迁时间线。

页面中的照片可能来自《影像苏州》等现代出版物。政府网站公开展示不代表图片采用开放许可。研究阶段可以记录、链接和核对；公开展示前应联系原出版方或权利人。

## 6. 人物与古树关系的证据等级

人物和古树之间最容易产生过度叙述。项目将证据分为三级：

| 等级 | 定义 | 页面可以怎样写 | 不应怎样写 |
|---|---|---|---|
| A：直接证据 | 文集、旧志、题记或档案明确记载某树、植树行为或可识别的树木个体 | “某志记载此处有……”“某人在文中写到……” | 不超出原文推断树龄或身份 |
| B：空间关系 | 人物明确居住、任职、游览或参与营建，但没有提及这棵树 | “某人与这一地点有关”“某年曾游此园” | “曾在此树下”“亲手种植” |
| C：时代背景 | 人物或事件与古树估测树龄大致同时，但缺少地点或文本联系 | 作为独立的时代背景说明 | “这棵树见证了某人或某事” |

苏州市地方志工作办公室的[范成大专题](https://dfzb.suzhou.gov.cn/dfzb/szdq/202607/5249dd62a19546e095abb6cb9300494b.shtml)可用于整理人物生平和石湖背景。若要把范成大与某株具体古树相连，仍需诗文、旧志、园林档案或其他直接记录。

## 7. 检索方法与关键词

### 7.1 文庙

同一地点在不同时代可能使用不同名称。检索时组合使用：

`苏州文庙`、`苏州孔庙`、`苏州府学`、`学宫`、`儒学`、`泮宫`、`大成殿`、`戟门`

再与这些词交叉：

`银杏`、`古树`、`手植`、`庭树`、`修葺`、`兵燹`、`风灾`、`府学人物`

### 7.2 沧浪亭

建议组合：

`沧浪亭`、`沧浪小志`、`沧浪亭志`、`沧浪亭新志`、`苏舜钦`、`韩世忠`、`梁章钜`、`可园`

再与这些词交叉：

`古木`、`乔木`、`竹`、`梅`、`松`、`柏`、`银杏`、`题咏`、`图咏`、`修园`、`重修`

### 7.3 旧照片

中文和英文旧称应并用：

`苏州`、`姑苏`、`吴县`、`Soochow`、`Suzhou`、园名英文译名、寺观名英文译名

只检索 `Soochow` 会混入上海的 Soochow Creek，应优先使用数据库的地点筛选器。

## 8. 版权与引用边界

| 材料 | 私人研究版本 | 将来公开版本 |
|---|---|---|
| 地方志中的历史事实 | 可以归纳并标注出处 | 可以归纳；保留精确引文和来源 |
| 古籍短引 | 可以合理引用 | 使用必要限度的短引；注明作者、篇名、版本、卷页 |
| 古籍扫描图 | 可用于内部核对 | 需确认扫描来源及平台许可 |
| 现代点校本、校注本 | 可查阅和少量引用 | 不复制整页、长段点校文字、注释或排版 |
| 官方网站文章 | 可整理事实和保存链接 | 以摘要和链接为主，不整篇转载 |
| 官方网站图片 | 可用于内部研究 | 未有明确许可时不直接展示 |
| CC BY-NC-ND历史照片 | 可在非商业研究场景原样使用并署名 | 不得裁切、调色或商用；公开方式需符合许可 |
| 公有领域或CC0图片 | 核对后使用 | 可公开使用；仍保留来源和状态证据 |

项目由私人研究转为公开发布时，应对所有图片、扫描页、现代整理文本和数据库导出内容重新审核。古书年代久远、政府网站公开可见、大学收藏或平台允许阅读，都不能单独作为开放转载的依据。

## 9. 项目引入顺序

第一批建议引入：

1. 苏州市地方志数据库；
2. 苏州方志办的地情、人物与老照片栏目；
3. 国家图书馆数字方志和古籍；
4. 《沧浪亭旧志汇编》所收五种原始文献；
5. 布里斯托大学的苏州历史照片；
6. 哈佛燕京图书馆的目录与书目数据；
7. CADAL中的近现代方志和文集，作为内部查阅来源。

第二批再补充：

- 各区县、乡镇、园林和寺观的专业志；
- 苏州档案馆、图书馆及园林管理机构的专题档案；
- 文人别集、年谱、家谱和地方艺文总集；
- 有明确开放许可的历史地图、老照片和建筑图像。

## 10. 资料登记字段

每一条史料至少登记以下字段：

| 字段 | 说明 |
|---|---|
| `source_id` | 项目内部唯一编号 |
| `title` | 题名或照片标题 |
| `creator` | 作者、编者、摄影者或机构 |
| `date` | 成书、出版、拍摄或发布年代 |
| `edition` | 版本、刻本、影印本或数据库版本 |
| `volume_page` | 卷次、篇名、页码或图片编号 |
| `institution` | 收藏、发布或维护机构 |
| `source_url` | 原始条目或永久链接 |
| `accessed_at` | 最后访问日期 |
| `source_type` | 方志、文集、档案、照片、地图、年鉴等 |
| `rights_statement` | 原页面的版权或许可原文 |
| `license` | CC许可、公有领域、版权所有或未声明 |
| `public_display` | 是否允许在公开页面展示 |
