# 资料源流——“以树为碑”外部资源与使用指南

本文件登记项目使用过或评估过的外部数据、图像、植物学资料和地方史资料，供采集、研究、编辑与前端开发人员共同参考。

- 版本日期：2026-08-16
- 适用范围：当前私人研究版本；若项目转为公开发布，必须重新执行版权复核
- 项目原则：来源可访问不等于允许转载；聚合平台标注不能替代原始页面的许可说明

## 1. 使用状态与许可标记

### 1.1 使用状态

| 状态 | 含义 |
|---|---|
| 已使用 | 已进入当前数据、地图或页面内容 |
| 已下载（研究用） | 已保存到本地，但不能据此推定可公开发布 |
| 已评估 | 做过检索或接口测试，尚未进入正式内容 |
| 备选 | 适合后续人工选材，尚未做系统测试 |
| 暂不采用 | 许可、匹配质量或获取方式不符合当前要求 |

### 1.2 常见许可

| 标记 | 基本要求 | 项目处理方式 |
|---|---|---|
| CC0 1.0 | 作者尽可能放弃相关权利 | 可用于公开版本；仍保留来源记录 |
| Public Domain / PDM | 作品被标示为公有领域；PDM 是状态标记，不是许可合同 | 核对国家、年代和原始来源后使用 |
| CC BY | 必须署名，并提供许可链接和修改说明 | 可用于公开版本 |
| CC BY-SA | 署名；衍生作品须采用相同许可 | 使用前确认页面组合是否构成衍生作品 |
| CC BY-NC | 禁止商业使用 | 仅可用于明确的非商业场景；不作为公开版本首选 |
| CC BY-ND / CC BY-NC-ND | 禁止演绎；可能同时限制商业使用 | 不裁切、不调色、不去水印；一般不进入本项目页面 |
| ODbL | 数据库署名和相同方式共享要求 | 适用于 OpenStreetMap 数据，不等同于瓦片服务器使用许可 |
| 版权所有 / 未声明 | 未获得再使用授权 | 仅做引用、链接或私人研究；公开展示前取得书面许可 |

许可判断以单个条目的来源页为准。照片许可、观测记录许可、数据库许可和网站服务条款应分别记录，不能相互替代。

当前对应结果：100 个名录树种均有检索记录；65 个树种下载到有效图像，29 个物种页没有 Illustration，5 个未找到独立分类单元，1 个原图不可用。严格核验 gallery 只展示 61 个名录树种，对重复图版去重后为 58 张；龙柏、龙爪槐、琼花和银薇等只匹配到基准种的条目被排除。

相关文件：

- `data/efloras-illustrations.json`：完整检索和下载清单
- `data/efloras-lineart.review.json`：严格展示的排除记录
- `data/source-images/efloras-foc/`：研究用原始下载
- `public/images/species/lineart/gallery.html`：当前本地核验页面
- `scripts/fetch_efloras_illustrations.py`：精确匹配和断点续传脚本
- `scripts/build_efloras_gallery.py`：严格 gallery 生成脚本

旧脚本曾在精确搜索失败后回退到属级并采用第一个结果，已证明会产生错误对应。后续不得恢复这种匹配方式。

## 9. 署名记录模板

每个媒体文件至少保存以下字段：

```text
标题 / 描述：
所描绘分类单元：
作者 / 创作者：
来源机构：
原始条目页：
原始文件地址：
许可名称与版本：
许可链接：
是否修改及修改内容：
下载日期：
审核人：
物种对应可信度：exact / accepted-synonym / parent-taxon / uncertain
```

页面署名建议格式：

```text
作者 · 来源机构 · 许可名称
```

示例：

```text
ScareCriterion12 · Wikimedia Commons · CC BY-SA 4.0
```

对于私人研究用 eFloras 图版：

```text
Flora of China Illustrations · Science Press & Missouri Botanical Garden Press · via eFloras.org · 私人研究使用
```

## 10. 采集与审核流程

1. 先从苏州名录读取中文名和原始学名。
2. 用 POWO、Flora of China、GBIF 或 Catalogue of Life 核对接受名和异名关系。
3. 栽培品种、变型、杂交种不能用基准种图像冒充精确图像。
4. 在候选来源中检索；禁止在精确匹配失败后直接回退到“同属第一条”。
5. 打开原始条目页，核对画面主体、作者、许可、来源和下载地址。
6. 将候选写入媒体清单，并保存许可链接和下载日期。
7. 由另一位合作人员复核物种和许可；未复核前状态不得设为 `published`。
8. 页面发布前检查署名是否可见、链接是否有效、修改说明是否完整。
9. 来源内容或许可发生变化时保留旧记录，新增审核日期，不覆盖历史判断。

## 11. 已确认的风险

- 自动检索容易把同属异种、普通果实、PDF 封面或包含目标词的整本扫描误判为物种图。
- 中文俗名可能对应多个分类单元；同一物种也可能在名录中出现多个中文名。
- 聚合平台的许可字段可能过期或继承错误，必须回到原始机构页面复核。
- “Public Domain”可能只适用于特定国家；“No Known Copyright”不是法律保证。
- 数据库开放许可不自动覆盖网页截图、照片、地图瓦片或第三方媒体。
- 当前项目为私人研究并不改变素材本身的版权状态；如果项目公开部署，eFloras、PPBC、CVH 和地方志图片必须重新评估。
